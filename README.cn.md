# cli

[English version](./README.md)

Open-source CLI to back up a Supabase project to your own S3/R2/B2 bucket (Postgres, Auth users when your role can read them, Storage files once you add the project's Storage S3 keys), then restore-drill it to prove the backup restores. Engine of backupdrill.com.
